# История версий

## 3.0.1

- Компактная страница обновлений: версии, проверка и установка.
- Убраны описание релиза, ссылка на релиз и отдельный блок состояния обновления.

## 3.0.0

- Страница проверки релизов и обновления панели из браузера.
- Независимый процесс установки с сохранением состояния при перезапуске панели.
- Блок установленной версии в нижней части бокового меню.
- Обновления доступны только после авторизации администратора; повторный запуск блокируется.

## 1.0.1

- Восстановление прерванного обновления доступно даже между переименованиями
  каталогов manager/venv; исправлен порядок записи маркера успешного обновления.

## 1.0.0

- Первый публичный релиз Aegis Redirection.
- Изолированные проверки серверов и резервирование по интерфейсам.
- Исправлено отображение адрес-листов.
- Настройки исходящего IP определяются по интерфейсам конкретной ВМ.
- Версионное обновление, предварительная проверка на копии базы и откат.
- Адрес-листы и секреты каждой ВМ сохраняются локально.
