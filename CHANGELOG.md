# История версий

## 3.1.8

- Исправлено объединение разных протоколов подписки на одном адресе и порту.
- Исправлено отображение сохранённых подписок: обновлены версии кэша веб-ресурсов и ошибки загрузки списка теперь видны.
- HEALTH сначала проверяет домен-маску (SNI) сервера через прокси, затем использует независимый резервный адрес.
- В каталоге показывается последняя задержка проверки, а не лучший исторический результат.

## 3.1.7

- Сохранённые подписки серверов автоматически синхронизируются раз в час; новые серверы добавляются без удаления или изменения существующих.
- Для подписок добавлены ручная проверка, пауза и удаление сохранённой ссылки; импортированные серверы остаются в каталоге.
- HEALTH учитывает любой полный HTTP-ответ через прокси, чтобы коды ответа целевого сайта не вызывали ложный FAIL.
- Проверки конфигурации и пороги переключения failover не менялись.

## 3.1.6

- Повторное подключение ждёт готовности локальной службы ZeroTier.
- Если команда `leave` не сработала, служба перезапускается, `leave` пробуется ещё раз, затем всё равно выполняется `join`.
- Результат `join` и Node ID показываются отдельно, чтобы было понятно, был ли создан повторный запрос.

## 3.1.5

- Вкладка ZeroTier позволяет выбрать автоматический маршрут или локальный IP конкретного интерфейса.
- Интерфейс можно применить к уже подключённой ВМ; старые кнопка и строка исходного IP удалены.
- При сбое подробности журнала отображаются прямо в панели.

## 3.1.4

- Повторная отправка запроса ZeroTier из панели для устройств, ожидающих авторизации или адреса.
- Перед каждым подключением ZeroTier закрепляется за исходным IP; повторный запрос сохраняет Node ID.

## 3.1.3

- ZeroTier привязывается к исходному IP физического интерфейса.
- Уже подключённые ВМ могут применить исходный IP с перезапуском службы ZeroTier.

## 3.1.2

- Кнопка подключения блокируется, пока ВМ уже в сети или ожидает разрешения.
- Подсказка сообщает, если после авторизации в ZeroTier Central ещё не назначен IP-адрес.

## 3.1.1

- Исправлены права системного ключа ZeroTier при установке из фоновой службы.

## 3.1.0

- Добавлена вкладка ZeroTier: настройка приватной сети, подключение ВМ и адрес для удалённого входа в панель.
- ZeroTier устанавливается и запускается отдельной службой по явному действию администратора.

## 3.0.1

- Компактная страница обновлений: версии, проверка и установка.
- Убраны описание релиза, ссылка на релиз и отдельный блок состояния обновления.

## 3.0.0

- Страница проверки релизов и обновления панели из браузера.
- Независимый процесс установки с сохранением состояния при перезапуске панели.
- Блок установленной версии в нижней части бокового меню.
- Обновления доступны только после авторизации администратора; повторный запуск блокируется.

## 1.0.1

- Восстановление прерванного обновления доступно даже между переименованиями
  каталогов manager/venv; исправлен порядок записи маркера успешного обновления.

## 1.0.0

- Первый публичный релиз Aegis Redirection.
- Изолированные проверки серверов и резервирование по интерфейсам.
- Исправлено отображение адрес-листов.
- Настройки исходящего IP определяются по интерфейсам конкретной ВМ.
- Версионное обновление, предварительная проверка на копии базы и откат.
- Адрес-листы и секреты каждой ВМ сохраняются локально.
