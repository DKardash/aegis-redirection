Настройка MikroTik

L2TP · два маршрута

1. L2TP-клиенты

Перед выполнением команд замените ВАШ_ЛОГИН и ВАШ_ПАРОЛЬ на данные для подключения к L2TP.

/interface l2tp-client add name=interface_VPN connect-to=192.168.0.95 \
    user=ВАШ_ЛОГИН password=ВАШ_ПАРОЛЬ profile=default \
    ipsec-secret=no add-default-route=no disabled=no

/interface l2tp-client add name=interface_VPN_L2TP connect-to=192.168.0.96 \
    user=ВАШ_ЛОГИН password=ВАШ_ПАРОЛЬ profile=default \
    ipsec-secret=no add-default-route=no disabled=no

2. Таблицы маршрутизации

/routing table add name=to_interface_VPN fib comment="Routing via interface_VPN"
/routing table add name=to_interface_VPN_L2TP fib comment="Routing via interface_VPN_L2TP"

3. Маршруты по умолчанию

/ip route add dst-address=0.0.0.0/0 gateway=interface_VPN routing-table=to_interface_VPN distance=1 comment="Default via interface_VPN"
/ip route add dst-address=0.0.0.0/0 gateway=interface_VPN_L2TP routing-table=to_interface_VPN_L2TP distance=1 comment="Default via interface_VPN_L2TP"

4. NAT

/ip firewall nat add chain=srcnat out-interface=interface_VPN action=masquerade comment="NAT via interface_VPN"
/ip firewall nat add chain=srcnat out-interface=interface_VPN_L2TP action=masquerade comment="NAT via interface_VPN_L2TP"

Редактирование .rsc

Формат: секции-заголовки # ===== N. Название =====, строки /ip firewall address-list и add list=TELEGRAM_DNS comment="..." address=.... Доступны TELEGRAM_DNS, DISCORD_DNS и PUBG_DNS. При сохранении создаётся резервная копия.

Скрипт синхронизации для MikroTik

Обновляет записи в списках TELEGRAM_DNS, DISCORD_DNS и PUBG_DNS (домены, не зарезолвленные здесь, роутер дорезолвит сам). Вставьте весь блок в терминал RouterOS.

Импорт записей

Каждая строка — add list=ИМЯ comment="..." address=.... Импорт добавит новые записи и обновит комментарии у совпавших адресов, не удаляя остальные.
